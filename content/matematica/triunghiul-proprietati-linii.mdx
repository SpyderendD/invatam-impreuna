# Triunghiul: Proprietăți și Linii Importante

  <p>

## 1. Proprietăți fundamentale

Indiferent de tipul triunghiului, aceste reguli sunt mereu adevărate:

1.  **Suma măsurilor unghiurilor interne** este întotdeauna **$180^\circ$**.
    $$\measuredangle A + \measuredangle B + \measuredangle C = 180^\circ$$
2.  **Inegalitatea triunghiului:** Lungimea oricărei laturi este mai mică decât suma celorlalte două și mai mare decât diferența lor.
    $$|b - c| < a < b + c$$
3.  **Unghiul exterior:** Măsura unui unghi exterior este egală cu suma unghiurilor interne nealăturate lui.

---

## 2. Clasificarea triunghiurilor

### A. După lungimea laturilor:
*   **Oarecare (scalen):** Toate laturile au lungimi diferite.
*   **Isoscel:** Are două laturi egale. Unghiurile de la bază sunt de asemenea egale.
*   **Echilateral:** Toate cele trei laturi sunt egale. Toate unghiurile au $60^\circ$.

### B. După măsura unghiurilor:
*   **Ascuțitunghic:** Toate unghiurile sunt $< 90^\circ$.
*   **Dreptunghic:** Are un unghi de $90^\circ$. Laturile care formează unghiul drept se numesc *catete*, iar latura opusă se numește *ipotenuză*.
*   **Obtuzunghic:** Are un unghi $> 90^\circ$.

---

## 3. Linii importante în triunghi

Fiecare triunghi are patru seturi de linii speciale care se întâlnesc în puncte unice (puncte de concurență).


### 1. Bisectoarea
Este semidreapta care împarte un unghi în două părți egale.
*   **Punctul de intersecție:** Se numește **Incentru ($I$)**.
*   **Proprietate:** Este centrul cercului **înscris** în triunghi (egal depărtat de laturi).

### 2. Mediatoarea
Este dreapta perpendiculară pe mijlocul unei laturi.
*   **Punctul de intersecție:** Se numește **Centrul cercului circumscris ($O$)**.
*   **Proprietate:** Este centrul cercului care trece prin toate vârfurile triunghiului.

### 3. Mediana
Este segmentul care unește un vârf al triunghiului cu mijlocul laturii opuse.
*   **Punctul de intersecție:** Se numește **Centru de greutate ($G$)**.
*   **Proprietate:** Se află la $\frac{2}{3}$ de vârf și $\frac{1}{3}$ de bază pe fiecare mediană.

### 4. Înălțimea
Este segmentul perpendicular dus dintr-un vârf pe latura opusă.
*   **Punctul de intersecție:** Se numește **Ortocentru ($H$)**.

## 4. Exercițiu Rezolvat

<ExampleBlock title="Aflarea unghiurilor necunoscute" type="math">
  **Problemă:** Într-un triunghi isoscel $ABC$, măsura unghiului de la vârf ($\hat{A}$) este de $40^\circ$. Aflați măsurile unghiurilor de la bază ($\hat{B}$ și $\hat{C}$).

  **Rezolvare:**
  1. Știm că într-un triunghi isoscel, unghiurile de la bază sunt egale: $$\measuredangle B = \measuredangle C$$.
  2. Știm că suma unghiurilor este $180^\circ$:
     $$\measuredangle A + \measuredangle B + \measuredangle C = 180^\circ$$
  3. Înlocuim $\measuredangle A$ cu $40^\circ$ și notăm $\measuredangle B$ cu $x$:
     $$40^\circ + x + x = 180^\circ$$
     $$40^\circ + 2x = 180^\circ$$
  4. Rezolvăm ecuația:
     $$2x = 180^\circ - 40^\circ$$
     $$2x = 140^\circ \implies x = 70^\circ$$

  **Răspuns:** Unghiurile de la bază au fiecare **$70^\circ$**.
</ExampleBlock>

## 5. Rezumat Puncte de Concurență

| Linia Importantă | Simbol Punct | Denumire Punct | Legătura cu Cercul |
| :--- | :---: | :--- | :--- |
| **Bisectoarea** | $I$ | Incentru | Centrul cercului **înscris** |
| **Mediatoarea** | $O$ | Centrul circumscris | Centrul cercului **circumscris** |
| **Mediana** | $G$ | Centru de greutate | Centrul de echilibru (balans) |
| **Înălțimea** | $H$ | Ortocentru | - |
